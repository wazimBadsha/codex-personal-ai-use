# Deep Coding Engineering Kit v2.0.0

A clean, portable Codex skill distribution containing the universal engineering skill and enterprise research/evidence-control policy.

## Contents
- `.agents/skills/deep-coding-engineering/SKILL.md` — Codex-discoverable universal engineering skill
- `.codex-plugin/plugin.json` — Codex plugin manifest
- `policy/DEEP-RESEARCH-ENTERPRISE-CONTINUOUS-v1.0.md` — research/evidence policy

The accompanying ChatGPT artifact ZIP contains the expanded 31-module engineering skill library, validation tooling, manifests, and evaluation set.

## Codex use
Codex discovers repository skills under `.agents/skills/` and user-level skills under the universal `.agents/skills/` location. Copy the `deep-coding-engineering` skill directory to the appropriate supported scope or install the plugin using the runtime's supported plugin mechanism.

## Verification boundary
Presence of the files proves distribution only. It does not prove that a target Codex runtime has discovered, invoked, executed, or persisted the skill. Test those states independently.

## Safety
No credentials, API keys, private keys, production data, proprietary source code, or opaque executable payloads are included in this distribution.
